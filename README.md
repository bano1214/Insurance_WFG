# Bano Batool — Insurance & Family Protection

Professional single-page website for Bano Batool, an Ontario-licensed insurance agent based in Milton, Ontario, affiliated with World Financial Group (WFG).

## Website contents

- Life insurance and financial protection information
- Children's future planning considerations
- Mortgage and family protection reviews
- Insurance agent career information
- Direct contact links: bbatool31avrc@wfgmail.ca and (437) 236-8683

The site is implemented in [index.html](./index.html), with responsive CSS and no external dependencies.

## Preview locally

Download the repository and open `index.html` in a browser.

## Publish with GitHub Pages

**Important:** Obtain applicable WFG advertising/compliance approval before public promotion or enabling a live website.

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. When GitHub confirms deployment, the site should be available at:
   https://bano1214.github.io/Insurance_WFG/
